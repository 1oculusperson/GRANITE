# GRANITE
full game of yosemitee valley!! it has everything fully accurate except for seasons and obviously graphics, full multiplayer functionality but its untested, if you find any bugs lmk :) adding story mode soon, itll be spooky


## Download and play

**[Get the latest release](https://github.com/1oculusperson/GRANITE/releases/latest)**

- **[Windows](https://github.com/1oculusperson/GRANITE/releases/latest/download/GRANITE-Launcher.zip):** extract the ZIP and open `GRANITE Launcher.exe`.
- **[Mac Apple Silicon preview](https://github.com/1oculusperson/GRANITE/releases/latest/download/GRANITE-Mac-AppleSilicon-Preview.zip):** M1 or newer, macOS 14/15/26. Extract the ZIP and open `GRANITE.command`. Follow its Terminal prompts. **Not yet tested on a physical Mac; not Apple-notarized.** Read the release notes before installing.

Keep all launcher files together. Each launcher downloads the game and asks before installing future updates. No GitHub login is required. Downloads are around 2.4 GB after the small launcher ZIP; allow at least 10 GB free for installation and retain space for old versions.

Do not download the automatic Source code ZIP to play. The `chunk-*.gz` and manifest files on the release page are downloaded automatically by the launchers.

## Multiplayer

Open Multiplayer, then Browse games to join an Internet lobby or Host game to create one. Epic provides discovery and relay fallback, so no port forwarding is required. Story mode is a disabled placeholder for now.

This repository hosts game releases. Licenses and attribution are included with the downloaded game. Both launchers are development builds; see each release for testing limitations.
